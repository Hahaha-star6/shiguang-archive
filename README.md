# 拾光档案 · 大学生成长档案工作台

> 证书照片拖进来，AI 自动识别、脱敏、归档，毕业时一键生成简历。
> 基于 [TextIn xParse](https://www.textin.com) 的本地网页小应用，**数据全程只存在你自己电脑上**。

## 这是什么

大学四年攒下的奖学金证书、志愿者证明、四六级成绩单、学生证、学位证……
真到填简历、参加面试时，却翻遍相册找不齐。

拾光档案把这些"纸"变成一个会成长的档案库：

1. **拍照上传** → xParse 把照片/PDF 识别成文字（拍歪了能自动转正）
2. **智能提取** → 自动生成标题、颁发单位、时间、摘要、亮点标签，并按类型分类
3. **自动脱敏** → 学号、身份证号"保头保尾"打码（如 `2024****12`）
4. **成长档案** → 每张经历卡片都带原件照片，重复上传自动提醒，假图片当场拦截
5. **一键简历** → 多套模板 + 上传截图自定义配色、AI 三档文案润色、导出 PDF

## 三步跑起来（Windows，全程不用写代码）

### 第 1 步：装 Python

到 https://www.python.org/downloads/ 下载 Python 3.10 或更高版本。
安装时**务必勾选最下面的 `Add python.exe to PATH`**，再点 Install。

### 第 2 步：装 xParse 命令行工具并登录（免费额度每天 1000 页）

先装 Node.js LTS 版：https://nodejs.org/ （一路下一步即可）。
然后打开命令提示符（Win+R 输入 `cmd` 回车），执行：

```bash
npm install -g xparse-cli
xparse-cli auth
```

`xparse-cli auth` 会弹出登录菜单，按提示用浏览器登录你的 TextIn 账号即可。
没有账号就到 https://www.textin.com 免费注册（注册时可填比赛邀请码 `JGMWC4`，可选）。

登录后可以用这两个命令自查：

```bash
xparse-cli auth status     # 查看登录状态
xparse-cli quota           # 查看今日剩余额度
```

### 第 3 步：双击启动

双击项目文件夹里的 **`start.bat`**，黑窗口会保持打开，浏览器自动弹出档案馆首页。
`输入照片` 文件夹里附了 15 张虚构的模拟证件（主角"王小明"），可以直接拿来体验全流程。

> 黑窗口就是服务本身，使用期间**最小化可以，别点 ×**。
> 不小心双击两次也没关系：程序发现服务已在运行，会直接帮你打开浏览器。

## 目录说明

```
拾光档案/
├─ start.bat            ← 双击启动（Windows）
├─ server.py            ← 本地服务（识别/提取/脱敏/文件安检，端口 8765）
├─ desensitize.py       ← 敏感信息脱敏模块（可单独命令行使用）
├─ auto_archive.py      ← 可选：命令行批量归档（python auto_archive.py）
├─ 网页档案馆/
│  ├─ index.html        ← 档案馆首页：上传证书、经历卡片墙
│  ├─ profile.html      ← 个人中心：学生证识别、多段学历
│  ├─ resume.html       ← 简历工作台：模板/润色/导出
│  └─ feedback.js       ← 三页共用的反馈弹窗
└─ 输入照片/             ← 上传原件自动归档到这里（附模拟素材）
```

首次运行后会自动生成 `解析结果` 等运行目录，属于正常现象。

## 隐私说明

- 证书照片只保存在**本机**`输入照片`文件夹，卡片和个人信息只保存在**浏览器 localStorage**，不向任何第三方数据库上传
- 唯一的网络请求是把图片发给 TextIn xParse 做 OCR 识别
- 身份证号、学号等在展示与保存时自动打码；如需彻底清理，删掉浏览器站点数据即可

## 常见问题

**Q：双击 start.bat 黑窗口一闪而过？**
A：新版脚本失败时会停住显示原因。如果提示 Python 找不到，说明第 1 步没勾选 PATH，重装 Python 勾上即可。

**Q：提示 `xparse-cli 不是内部或外部命令`？**
A：Node.js 没装，或装完没重开命令行。装好 Node.js 后重新打开 cmd 执行 `npm install -g xparse-cli`。

**Q：识别一直失败 / 提示额度问题？**
A：先跑 `xparse-cli auth status` 确认已登录、`xparse-cli quota` 看额度；再确认照片清晰、格式为 jpg/png/bmp/webp/tiff/pdf。

**Q：8765 端口被其他软件占用了？**
A：关掉占用端口的程序即可；若占用者正是本服务，直接打开 http://127.0.0.1:8765/ 就行。

**Q：换了浏览器 / 清理缓存后卡片没了？**
A：数据存在浏览器本地，属于设计如此（零后端、零隐私泄露）。
